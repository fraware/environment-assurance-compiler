## Hard exclusions for good-first issues

Do **not** label as good-first:

- Authorization redesign
- Snapshot integrity redesign
- Security-boundary redesign

See [CONTRIBUTING.md](https://github.com/fraware/environment-assurance-compiler/blob/main/CONTRIBUTING.md) and [governance](../governance/index.md).
